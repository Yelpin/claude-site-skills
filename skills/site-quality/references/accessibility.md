# Доступность — WCAG 2.2 AA сверх контраста

Контраст проверяет `scripts/contrast-check.js`. Это остальное — то, что ломается чаще всего и что site-quality обязан ловить. Доступность = требование, не опция.

## Клавиатура и фокус
- **Всё кликабельное достижимо с Tab** и срабатывает по Enter/Space. Кастомные «кнопки» на `<div>` без роли и обработчика — недоступны.
- **`focus-visible` виден всегда.** Не убивай `outline: none` без замены. Обводка контрастная, заметная.
- **Порядок фокуса логичен** — идёт по смыслу (сверху вниз, слева направо), не прыгает. DOM-порядок = визуальный порядок.
- **Фокус-ловушки:** в модалке фокус заперт внутри, Esc закрывает, при закрытии возвращается на триггер.
- **Skip-link** «к содержимому» первым в табе для страниц с крупной навигацией.

## Семантика и структура
- **Нативные теги.** `<button>`, `<a href>`, `<nav>`, `<main>`, `<header>`, `<footer>`, `<h1..h6>` — а не `<div>` на всё. Скринридер и клавиатура получают поведение бесплатно.
- **Один `<h1>`, заголовки по уровням** без прыжков (h1→h3 — плохо).
- **Landmarks:** `<main>`, `<nav>`, `<footer>` для навигации по регионам.
- **Ссылка vs кнопка:** переход — `<a>`; действие — `<button>`. Не наоборот.

## Контент
- **`alt` осмысленный** у значимых картинок (что на них, а не имя файла); декоративные — `alt=""`.
- **Иконка-кнопка без текста** — `aria-label`.
- **Формы:** каждое поле с `<label>` (не только placeholder); ошибки связаны с полем (`aria-describedby`), объявляются, а не только краснеют. (детали — `forms-and-inputs.md`)
- **Цвет не единственный носитель смысла:** ошибка — не только красный, но и текст/иконка; ссылка в тексте — не только цветом.

## Движение и медиа
- **`prefers-reduced-motion: reduce`** глушит нефункциональную анимацию. Параллаксы, автоплей-карусели, крупные переходы — под гейт.
- Автоплей-видео — без звука, с паузой; ничего не мигает чаще 3 раз/сек (риск эпилепсии).

## Приземляющий чек
- [ ] Прошёл всю страницу только с клавиатуры — всё достижимо, фокус видно.
- [ ] Заголовки по уровням, теги нативные, landmarks на месте.
- [ ] Все картинки с корректным `alt`; иконки-кнопки с меткой.
- [ ] Ошибки/статусы не только цветом.
- [ ] `prefers-reduced-motion` уважается.
