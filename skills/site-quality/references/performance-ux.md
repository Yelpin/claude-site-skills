# Перф как UX — воспринимаемая скорость

Core Web Vitals (пороги — в SKILL.md site-quality) отвечают на «быстро ли по метрике». Этот файл — про «ощущается ли быстро». Часто ощущение важнее цифры.

## Воспринимаемая скорость
- **Скелеты вместо спиннеров.** Каркас контента (серые блоки формы страницы) читается как «уже грузится и вот-вот будет», спиннер — как «висит».
- **Оптимистичный UI.** Действие отражается сразу (лайк поставлен, товар в корзине), сеть догоняет в фоне; ошибка → мягкий откат.
- **Приоритет первого экрана.** Сначала грузим и показываем то, что видно; остальное — лениво. Человек уже читает, пока низ догружается.
- **Мгновенная реакция на ввод** (120–200 мс) важнее, чем общая скорость: интерфейс, который откликается, кажется быстрым даже при медленной сети.

## Что бьёт по метрикам (и как чинить)
- **LCP (≤ 2.5c)** — герой-картинка: правильный размер (не 4000px в слот 800px), формат WebP/AVIF, `fetchpriority="high"`, без `lazy` на первом экране, preload ключевого. Шрифт заголовка — не блокирует рендер.
- **CLS (≤ 0.1)** — резервируй место: `width`/`height` или `aspect-ratio` у картинок/видео/эмбедов; не вставляй баннеры/шрифты, толкающие контент; `font-display: swap` + подобранный фолбэк-метрикой шрифт.
- **INP (≤ 200мс)** — не блокируй главный поток тяжёлым JS; дроби длинные задачи; вешай обработчики экономно; тяжёлое — после интерактива.

## Ресурсы
- **Картинки** — обычно главный вес. Форматы, размеры под слот, `srcset` для ретины/мобайла, `loading="lazy"` на некритичных.
- **Шрифты** — только используемые начертания и наборы символов; `font-display: swap`; желательно self-host / `@fontsource`, чтобы не ждать сторонний домен.
- **JS** — код-сплит, не тащи всю библиотеку ради одной функции; анимации — `transform`/`opacity` (см. `site-motion`).
- **Тяжёлое (3D/видео)** — ленивая инициализация, мобильный фолбэк, не автостарт на слабом соединении.

## Приземляющий чек
- [ ] Долгие загрузки — скелет/прогресс, не голый спиннер.
- [ ] Первый экран приоритетен, ниже — лениво.
- [ ] Герой-картинка оптимизирована и приоритетна; под медиа зарезервировано место (нет прыжков).
- [ ] Шрифты — swap + только нужное; JS не блокирует ввод.
- [ ] Lighthouse ≥ 90; LCP ≤ 2.5c, INP ≤ 200мс, CLS ≤ 0.1.
