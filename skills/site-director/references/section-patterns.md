# Паттерны секций — ломай скелет под тип сайта

Главное правило site-director: один и тот же скелет (хедер → крупный заголовок → строки → цифры → CTA) на каждом сайте = шаблон.
Магазин ≠ журнал ≠ портфолио ≠ SaaS по структуре. Ниже — архетипы секций и как их собирать под тип.

## Универсальные секции (общий словарь)
Герой · доказательство (соцпруф/логотипы/цифры) · суть-ценность · как работает · продукт/галерея · возражения (FAQ) · призыв · подвал.
Не обязателен весь список. Бери нужное, порядок — от главного вопроса аудитории.

## Лендинг / SaaS
- **Герой:** одна ясная ценность + один primary CTA + продуктовый кадр (реальный экран, не абстракция).
- **Логика:** проблема → решение → как работает (3 шага) → соцпруф → цены → FAQ → финальный CTA.
- **Сигнатура:** живой продуктовый момент (интерактивное демо, анимированный экран).
- **Не делай:** пять фич-карточек с иконками-заглушками подряд.

## Интернет-магазин
- **Герой:** не слоган, а вход в товар — категория/подборка/бестселлер с ценой сразу.
- **Логика:** витрина → фильтры/категории → карточка товара (крупные фото, цена, наличие, доставка) → доверие (отзывы, гарантии) → корзина.
- **Сигнатура:** качество продуктовой съёмки; сетка, которая дышит.
- **Не делай:** маркетинговый лендинг-скелет поверх каталога.

## Журнал / медиа / эссе
- **Герой:** заголовок-звезда + подводка + дата/автор; типографика несёт всё.
- **Логика:** статья/лента → навигация по темам → связанное чтение → подписка.
- **Сигнатура:** типографическая система, буквица, линии-разделители, читаемая мера строки (~65–75 символов).
- **Не делай:** CTA-«купи» через каждые два абзаца.

## Портфолио / личный сайт
- **Герой:** кто ты + чем силён в одну фразу; не «Добро пожаловать».
- **Логика:** работы (кейсы крупно) → о себе → процесс/подход → контакт.
- **Сигнатура:** один сильный проект во всю ширину; остальное тише.
- **Не делай:** сетка одинаковых квадратов-превью без иерархии.

## Агентство / студия
- **Герой:** позиция и характер (чем вы отличаетесь), не «мы делаем сайты».
- **Логика:** манифест → услуги → отобранные кейсы → команда → контакт.
- **Сигнатура:** смелая типографика или один эффектный скролл-момент.
- **Не делай:** стоковые фото рукопожатий и «наши ценности» тремя иконками.

## Приземляющий чек
- [ ] Скелет отличается от «дефолтного лендинга» и оправдан типом?
- [ ] Порядок секций отвечает на главный вопрос ИМЕННО этой аудитории первым?
- [ ] Есть секция-доказательство (не только обещания)?
- [ ] Один primary CTA доминирует; вторичные — тише?
