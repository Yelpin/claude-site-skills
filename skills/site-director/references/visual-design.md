# Визуальная система — тип, цвет, отступ, ритм

Если вкус-тул задаёт токены — следуй ему. Этот файл — метод, когда токены задаёшь сам (фолбэк) и чтобы site-quality было с чем сверять.

## Типографика
- **Шкала — модульная, не «на глаз».** База 16px, шаг ~1.25 (мажорная терция): 12 / 14 / 16 / 20 / 25 / 31 / 39 / 49 / 61. Округляй к удобному (12/14/16/20/28/44/72). Одна шкала на весь сайт.
- **Пара по ролям, не по моде.** Дисплейный (характер, заголовки) + текстовый (читаемость, тело) + опц. mono (метки/цифры). Максимальный контраст между парой — не два похожих гротеска.
- **Мера строки** тела: 60–75 символов. Шире — глаз теряет строку.
- **Интерлиньяж:** тело ~1.5; крупные заголовки ~1.05–1.15 (плотнее).
- **Вес и трекинг:** крупному — минусовой трекинг, мелким КАПСом — плюсовой. Не более 2–3 весов.

## Цвет
- **60 / 30 / 10.** 60% — доминирующий нейтрал (фон), 30% — вторичный, 10% — акцент (CTA, ссылки). Акцент — редко, тогда он работает.
- **Семантические токены, не хексы в разметке.** `--bg`, `--surface`, `--ink`, `--muted`, `--accent`, `--border`, `--danger`, `--success`. Меняешь тему — правишь токены.
- **oklch** для управляемых оттенков: одинаковая воспринимаемая яркость по акцентам, ровные шкалы. `oklch(0.7 0.15 250)`.
- **Тёмная тема — не инверсия.** Отдельные значения: фон не чистый #000, текст не чистый #fff (мягче — #e8e8e8 на #121212). Акцент часто чуть светлее/менее насыщен.
- **Контраст — по контрасту, не по «красиво».** Проверять `site-quality/scripts/contrast-check.js`. Порог AA: тело ≥ 4.5:1, крупное ≥ 3:1.

## Отступы и сетка
- **8-point grid.** Все отступы кратны 8 (или 4 в мелком): 4 / 8 / 16 / 24 / 40 / 64 / 96. Один шаг на весь сайт.
- **Ритм секций:** вертикальный отступ между блоками — из той же шкалы, крупный (64/96), одинаковый. «Выровняй отступы всех секций по одной шкале».
- **Воздух — не пустота, а иерархия.** Больше воздуха вокруг главного = взгляд идёт туда.
- **Сетка:** 12 колонок для сложного, простая центрированная колонка (max-width ~1100–1280) для лендинга. Контент не шире меры читаемости.

## Глубина
- Одно решение теней на весь сайт (мягкая, низкая, реалистичная — не «выпуклая кнопка 2010»). Или совсем без теней — плоско, но тогда иерархия через цвет/размер/линии.
- Радиус — одно значение (0 для строгого, 8–12 для дружелюбного). Не смешивай острое и круглое без причины.

## Приземляющий чек (сверяет site-quality)
- [ ] Кегли только из шкалы; отступы только кратны 8.
- [ ] 4–6 именованных цветов; акцент ≤ 10% площади.
- [ ] Тёмная тема заданными значениями, не `invert`.
- [ ] Мера строки тела 60–75 символов.
