# Адаптив — мобайл не «ужатый десктоп»

Правило site-director «проверь на 390px» — здесь метод. Мобильный трафик обычно больше половины; проектируй под палец, потом расширяй.

## Стратегия
- **Mobile-first.** Базовые стили — под узкий экран, `min-width` медиа добавляют для широких. Так не забудешь мобайл.
- **Контент-приоритет.** На узком главное идёт первым, вторичное сворачивается/уходит вниз. Не пытайся впихнуть весь десктоп.
- **Брейкпоинты по контенту, не по устройствам.** Ставь точку там, где макет ломается, а не «под iPhone». Типичные ориентиры: ~640 / 768 / 1024 / 1280.

## Fluid-типографика и отступы
- `clamp()` вместо ступеней: `font-size: clamp(2rem, 5vw + 1rem, 4rem)` — плавно между мин и макс, без скачков на брейке.
- Отступы секций тоже fluid: `clamp(3rem, 8vw, 6rem)`. Крупные поля не съедают весь экран на мобильном.

## Раскладка
- **Container queries** для компонентов, которые живут в разных контекстах: карточка перестраивается по ширине контейнера, а не вьюпорта.
- Многоколонник → одна колонка на мобильном; горизонтальный скролл только осознанно (галерея), не для основного контента.
- Таблицы: на узком — карточки или горизонтальный скролл в своём контейнере (`overflow-x`), страница не едет вбок.

## Палец и жесты
- Тап-цель ≥ 44×44px, между целями зазор ≥ 8px.
- Важное — в зоне большого пальца (низ/центр экрана); не прячь primary-действие в верхний угол.
- Не вешай функциональность только на hover — на тач-экране hover нет. Hover — усиление, не единственный путь.
- Свайпы/жесты — с видимой альтернативой (стрелки/точки), не как единственный способ.

## Навигация на мобильном
- Гамбургер — ок, но primary-CTA лучше держать видимым (в шапке или закреплённым снизу).
- Меню открывается быстро, закрывается легко, фокус ведётся внутрь и обратно.

## Тяжёлое
- 3D/видео/крупные анимации — лёгкий фолбэк на мобильном (статичный кадр, упрощённая версия). Проверяй на реальном среднем телефоне, не только в эмуляторе.

## Приземляющий чек (на 390px)
- [ ] Ничего не разъезжается, страница не едет вбок.
- [ ] Кегли и отступы fluid, без скачков.
- [ ] Тап-цели ≥ 44px, primary-действие достижимо большим пальцем.
- [ ] Ничего критичного не спрятано только в hover.
- [ ] Тяжёлое имеет мобильный фолбэк.
